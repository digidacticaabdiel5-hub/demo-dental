# Demo de consultorio dental (datos ficticios)

Sitio estático para probar en Netlify. No lleva datos de ningún negocio real.

## Subir a Netlify
1. Entra a https://app.netlify.com/drop
2. Arrastra esta carpeta (`demo-dental`) completa.
3. Netlify te da una dirección tipo `algo.netlify.app`.

## Probar las citas
Las citas abren WhatsApp con el mensaje listo. El número de `config.js` (`whatsapp`) es de relleno:
cámbialo por tu propio número (52 + 10 dígitos) antes de subir si quieres ver el flujo completo.

## Notas
- Lleva `noindex`: Google no debería listarlo.
- El aviso de privacidad es solo de ejemplo.
